> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution, already chosen:** a Sonnet 5.5 (high) implementer does the whole plan, then fresh Opus 5.5 reviewers
> review it in a loop until one passes it. The implementer **commits nothing**: everything stays uncommitted for the
> orchestrator.

**Goal:** Kanban card 171, batch 2: `GET /v1/terminals/{block}/stream` (a terminal's screen, live, as SSE frames a
remote `Terminal::viewer` can redraw), `POST /v1/terminals/{block}/input` (paste or keys, as the person's keyboard),
the state's tick at 100 ms while a block is dragged, resized or the canvas panned, and the shown workspace's camera as
`view` in the state and, on request, on the event stream.

**Architecture:** `templum-terminal` gains a non-blocking reader of a terminal's live screen (`SharedTerm::screen`,
`try_lock_unfair`, None when the lock is held) and a change counter (`SharedTerm::changes`), so the reader looks only
at terminals that changed. `templum-api` (now depending on `templum-terminal`, UI-free) gains `terminals.rs`: a table of
the terminals the glue lends (block, workspace, `SharedTerm`), the terminal streams, and a reader task on the server's
runtime that every 50 ms turns each changed terminal into one frame per stream (whole first and after falling behind,
then only the changed rows). Opening a stream asks the UI thread (`templum/terminal`) to check the block against the
token and lend every terminal; the glue's tick lends them again while a terminal stream is open, so a closed or moved
block ends its streams. Input is an API-own tool, `terminal_input`, run on the UI thread like every tool. The `view`
rides on the state's existing comparison.

**Tech Stack:** Rust 2024; batch 1's crates (hyper 1, tokio, tokio-rustls, serde, serde_json…); `alacritty_terminal`
0.26 (already `templum-terminal`'s); GPUI through gpui-kit 0.7.3 (pinned) for the glue. No new external crate.

**Spec:** [docs/specs/api.md](../specs/api.md), whole, and its **Batch 2** section with the designer's calls under
"Designed" (they are this plan's decisions; read them before Task 1). Then the code this builds on:
`crates/templum-api/src/{server,events,registry,openapi,model,lib}.rs`, `crates/templum-api/tests/{common/mod,events,
server}.rs`, `crates/templum/src/workspace/{api,api_state}.rs`, `crates/templum/src/workspace/delegate.rs`
(`keys_in`, `press_keys`, `KEY_GAP`), `crates/templum/src/workspace/control.rs` (`find_block`, `no_block`,
`Call::SendToTerminal`'s arm), `crates/templum-terminal/src/{terminal,snapshot,input,lib}.rs` (`SharedTerm`, `Shared`,

## Global Constraints

- **MEMORY LIMITS on this machine** (systemd-oomd has killed builds and the app several times): **every** cargo command
  takes `-j 4` (`cargo build -j 4`, `cargo test -j 4`, `cargo clippy -j 4`, `cargo run -j 4`); **never two cargo
  commands at once** (no background build while a test runs); while working, run only the targeted tests each step
  names (`cargo test -j 4 -p <crate> --lib <module>::`, `cargo test -j 4 -p <crate> --test <file> <name>`,
  `cargo test -j 4 -p templum --bin templum workspace::tests::api::<name>`); the full suite **once**, in Task 7.
- **Crate boundaries:** only `crates/templum` depends on gpui-kit. `templum-api` now depends on `templum-mcp` and
  `templum-terminal` (both UI-free), never on `templum`. `templum-terminal` gets no serde: the JSON types live in
  `templum-api/src/model.rs` beside the state's. No `unsafe`. No new external crate: `Cargo.lock` gains no package;
  `cargo deny check` passes unchanged.
- **Every feature in the API** (CLAUDE.md, card 171): every route is a row of `registry::ROUTES` and every tool is in
  `registry::tools()`, so both are in `GET /v1/tools` and the OpenAPI document; docs/api.md gets their lines in Task 7.
- **Batch 1's security holds for terminals:**
  - A workspace-limited token reaches only the terminals of its workspaces; any other block (or one that doesn't
    exist) is `404` with `registry::no("block", id)`'s words, never `403`.
  - Tickets (`?ticket=`) open `GET /v1/events` **and** `GET /v1/terminals/{block}/stream`, nothing else.
  - A terminal stream holds a connection, so it counts in the 64 connections and in its token's 16; opening one is a
    call that takes from the token's bucket and is refused while the address is refused, as any request.
  - Revoking a token, its expiry, a change of its workspace list, *Disconnect*, turning the API off and quitting end its
    terminal streams at once, as they end its event streams (`Shared::sweep`, the heartbeat).
  - The audit log names an input call (`terminal_input`) and a stream (its path), with the status, and **never** the
    text, the keys or a ticket. No `Debug`, error or log line carries typed text either (an unknown key's own name may
    be echoed back to the caller who sent it, as `send_keys` does, never logged).
  - Input to a block that is gone is `404`; to one that isn't a terminal, a subagent's transcript or a shell that has
    ended, `422` with the sentence of Task 5.
- **Never block the UI thread, never slow painting:** the UI thread only clones `SharedTerm`s and hands them over under
  a lock the server holds no longer than a copy; the server reads a terminal with `try_lock_unfair` and skips it when
  the lock is held (never waits: the server's runtime is single-threaded and serves every connection); it never holds
  its own table's lock while it reads a terminal. With no terminal stream open the reader task sleeps and the server
  keeps no `SharedTerm`; with no stream of either kind the glue's tick doesn't run.
- **Values, verbatim** (from the spec's Batch 2): at most 20 frames a second per terminal (a look every 50 ms,
  `MissedTickBehavior::Delay`); 20 frames queued per terminal stream, then behind and a whole frame; the tick 100 ms
  while a block is dragged or resized or the canvas panned, else 250 ms; keys at most 16 a call (`tools::MAX_KEYS`),
  50 ms apart (`KEY_GAP`); text at most 256 KiB (`tools::MAX_TEXT`); heartbeat 15 s as events.
- **Words, verbatim:** "k9x1d isn't a terminal." (the block), "b7k2m's shell has ended: nothing typed reaches it.",
  "Pasted into b7k2m.", "Pressed 1 key in b7k2m.", "Pressed 2 keys in b7k2m.", "terminal_input takes text or keys.",
  "\"text\" is at most 256 KiB.", "\"keys\" holds 1 to 16 keys.",
  "keys[0] isn't a key Templum knows. Keys: <KEY_NAMES>." (the key's position, never the key: it may be a secret), "terminal_input needs a Full token.", "\"view\" is true or false.".
- **Every logic change has a test that fails without it.** Unit tests in `templum-terminal` and `templum-api`;
  integration tests over real HTTP in `crates/templum-api/tests/terminals.rs` (viewer terminals fed bytes: no PTY,
  every platform); headless GPUI tests in `crates/templum/src/workspace/tests/api.rs`. UI-only changes: say how they
  were verified.
- **Tests don't depend on HOME, config or installed agent CLIs**, and are stable under CPU load: wait on conditions
  with a 10 s deadline (`common::wait_for`), never one fixed sleep; a rate is asserted as an upper bound only.
  A test that needs a shell to echo is `#[cfg(unix)]`.
- **Minors** deferred go to `docs/minors.md` under `## API` (Task 7 lists them); docs lines ≤ 120 columns.
- **Reuse, don't copy:** `events::{frame, Cell, StreamBody, Ids}` for the streams, `ask` and `tool_answer`'s mapping
  for the UI round trip, `named_key`/`KEY_NAMES`/`tools::{MAX_KEYS, MAX_TEXT}` for input, `press_keys`' loop for keys,
  `Terminal::paste` for text, `registry::no` for the block words.
- **Commit nothing.** Every task ends with its tests passing, left uncommitted.

## Review Focus

1. **A streamed terminal's block is closed, or moved out of a limited token's workspaces:** its stream ends within a
   tick (EOF), and opening it again is `404` with the block words. → Task 3
   `a_stream_ends_when_its_terminal_leaves`; Task 4 `the_tick_lends_terminals_while_a_terminal_stream_is_open`.
2. **A token revoked while it streams a terminal:** the stream ends at once and its unused ticket is `401`. → Task 3
   `revoking_cuts_terminal_streams_and_their_tickets`.
3. **A phone asleep with a stream open on a terminal that prints nonstop:** the server holds at most 20 frames for it
   and it wakes to one whole frame of the newest screen, not a backlog. → Task 3
   `a_stream_behind_gets_the_newest_whole_frame`.
4. **The API on and nobody streaming:** no reader runs, no tick runs, and the server keeps no terminal (a closed
   block's grid and scrollback are not held alive). → Task 3 `the_terminals_are_kept_only_while_a_stream_is_open`;
   Task 4 `the_tick_lends_terminals_while_a_terminal_stream_is_open` (its last assertions).
5. **Esc and a key in one input** (`{"keys":["escape","j"]}`): they arrive 50 ms apart, not as Alt+j, and the answer
   comes after the last key, so the client's next input can't overtake them. → Task 5
   `terminal_input_pastes_and_presses_as_the_keyboard`.

**Interfaces:**
- Produces, in `templum_terminal`:
  - `pub enum Paint { Default, Index(u8), Rgb(Rgb) }` (`Clone, Copy, Debug, PartialEq, Eq`): a color as the program
    asked for it.
  - `pub struct Styled { pub text: String, pub fg: Paint, pub bg: Paint, pub bold: bool, pub dim: bool, pub italic:
    bool, pub underline: bool, pub inverse: bool }` (`Clone, Debug, PartialEq, Eq`): text of one style.
  - `pub struct Screen { pub cols: usize, pub rows: Vec<Vec<Styled>>, pub cursor: Option<Cursor>, pub title:
    Option<String> }` (`Clone, Debug, PartialEq, Eq`), `rows.len()` the screen's lines; `Cursor` is snapshot.rs's.
  - `impl SharedTerm { pub fn screen(&self) -> Option<Screen> }`: the **live** screen (rows `Line(0)..screen_lines`
    of the active grid, whatever the view is scrolled to; no selection), read under `self.0.try_lock_unfair()`; None
    when the lock is held, at once.
  - `impl SharedTerm { pub fn changes(&self) -> u64 }`: a counter in `Shared` (`AtomicU64`, `fetch_add(1, Release)`)
    bumped wherever `dirty` is set true (`Shared::wake`, `Shared::wake_now`, `SharedTerm::touched`), loaded with
    `Acquire`.
  - `impl SharedTerm { pub fn same(&self, other: &SharedTerm) -> bool }`: `Arc::ptr_eq` of their grids.
- **How a cell becomes a run** (the spec's Batch 2 "A run"): adjacent cells of equal style are one `Styled`.
  - Colors: a palette slot the program set (`term.colors()[slot]` is Some: OSC 4, 10, 11) is `Rgb` of it; else
    `Color::Spec(rgb)` → `Rgb`; `Color::Indexed(i)` → `Index(i)`; `Color::Named(n)` for `n < 16` → `Index(n)`, for
    `DimBlack..=DimWhite` → `Index(n - DimBlack)`; every other named color (the default foreground and background,
    their bright and dim forms, the cursor's) → `Default`.
  - Flags: `bold` = `BOLD`, `dim` = `DIM`, `italic` = `ITALIC`, `underline` = any of `Flags::ALL_UNDERLINES`,
    `inverse` = `INVERSE` (kept as a flag: the viewer swaps, not the reader).
  - Text: a `HIDDEN` cell is `' '`; a `WIDE_CHAR_SPACER` cell is left out; a `LEADING_WIDE_CHAR_SPACER` cell and a
    char below `' '` are `' '`; `cell.zerowidth()` chars follow their cell's char.
  - Trailing cells that are `' '` with `bg == Paint::Default`, not inverse and not underlined are trimmed; a run left
    empty goes. An empty row is `vec![]`.
  - Cursor: None unless `term.mode()` has `SHOW_CURSOR` and `term.cursor_style().shape` isn't `Hidden`; else
    `grid.cursor.point` (row, column), `shape` with `HollowBlock` given as `Block`, and `blinking`.
  - Title: `Shared::title()` (the program's OSC 0/2 title; blank is None).

    (its streams' next frame is whole).

- Produces, in `events.rs`: `Queue::new(cap: usize) -> Queue` (`Default` is `Queue::new(QUEUE)`; `push` past `cap`
  clears and is behind) and `Cell::new(cap: usize, behind: bool) -> Cell` (`Default` is `Cell::new(QUEUE, false)`).
- Produces, in `terminals.rs` (crate-private): `pub(crate) const FRAMES_QUEUED: usize = 20;`,
  `pub(crate) const FRAME_EVERY: Duration = Duration::from_millis(50);`, and `pub(crate) struct Screens` with:
  - `fn open(&mut self, caller: Caller, block: &str, conn: u64) -> (u64, Arc<Cell>)`: a stream, pending until its block

  - `fn admits(&self, id: u64) -> bool` (its block is lent and its caller sees its workspace);
  - `fn close(&mut self, id: u64)` (its cell ends; the last stream gone, every terminal is let go);
  - `fn set(&mut self, terminals: Vec<TerminalRef>)` (as `set_terminals` says);
  - `fn cut(&mut self, dead: impl Fn(&Caller) -> bool)`, `fn ping(&self)`, `fn len(&self) -> usize`,

    with a stream its `SharedTerm`, the `changes` it last read at, its last `Arc<Screen>` and its streams' cells; then
    without the lock: when `changes()` differs from it (or nothing was read yet), `screen()` (None: skip that terminal
    this round, nothing recorded, so the next round tries again), and `frame(last, &now)`; then under the lock again,
    for a terminal still `same` as copied: record the `changes` loaded **before** the read and the screen; each stream
    that is `behind` gets `resync` with the whole frame of the newest screen it has, the others `push` the frame when
    there is one. Frames are `events::frame(&ids.next().1, "frame", &json)`; a whole one is built once per terminal
    per round, only when a stream needs it.
- **The route** (`dispatch`'s GET branch, `Does::Frames`): `terminal_stream(shared, peer, token, block)`:
  `screens.open(…)` first (so the table is kept while the UI answers), wake the reader, then
  `ask(shared, token, TERMINAL, {"block"})`; an error, a `422` (`isError`) or a dropped request closes the stream and
  answers as `tool_answer` maps it; then `admits(id)` or close and `404` with `registry::no("block", block)`; then the
  connection's `streaming` is set and the response is the stream's `StreamBody` (its drop closes it and sets
  `streaming` to `hub.on_conn(conn) || screens.on_conn(conn)`), with the event stream's headers. `Last-Event-ID` is
  ignored: a terminal stream always opens whole.
- **Tickets:** `credentials` takes `?ticket=` on a GET whose `registry::find` is `Does::Events` or `Does::Frames`.
- **The reader task** (spawned beside `publisher` and `heartbeat`): `tokio::time::interval(FRAME_EVERY)` with
  `MissedTickBehavior::Delay`; while `screens.len() == 0` it awaits a `Notify` (`notify_one` from `open`, which keeps a
  permit), else `look` each tick.
- **Sweep and heartbeat:** `Shared::sweep` cuts the terminal streams with the same rule it cuts event streams with;
  the heartbeat pings them.
- **OpenAPI:** the operation of `Does::Frames`: scope `read`, `security` bearer or ticket, its path parameter,
  `text/event-stream`, a description naming `event: frame` and `#/components/schemas/Frame`.
