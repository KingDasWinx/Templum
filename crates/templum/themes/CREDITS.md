# Theme credits

The built-in themes are color lists in [Alacritty's format](https://alacritty.org/config-alacritty.html#colors).
Each file names its source in its first lines.

| Files | Source | License |
|---|---|---|
| `catppuccin-*.toml` | [catppuccin/alacritty](https://github.com/catppuccin/alacritty) at `f6cb5a5`, unchanged except for the header comment | MIT, below |
| `one-dark.toml`, `one-light.toml` | [alacritty/alacritty-theme](https://github.com/alacritty/alacritty-theme) `themes/one_dark.toml` and `themes/one_light.toml` at `ab88d5a`, unchanged except for the header comment | [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) |
| `apple-dark.toml`, `apple-light.toml` | Written for Templum from Apple's published system colors | MIT (Templum's license) |
